# 🏆 Sports Manager

A full-featured **Sports Management Web Application** built with Django, designed to simplify tournament and team management.  
It allows users to register, create teams, join tournaments, like/comment on events, and search or filter results — all in one platform.

---

## ✨ Features

- **User Authentication** – Register, log in, and reset passwords via email OTP.
- **Team Management** – Create, edit, and manage teams & members.
- **Tournament Management** – Create and register tournaments.
- **Tournament Registration** – Register teams and select players.
- **Social Features** – Like and comment on tournaments.
- **Search & Filter** – Quickly find tournaments or teams.
- **Dynamic UI/UX** – Styled forms, interactive effects, and responsive design.

---

## 🛠 Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite / MySQL (configurable)
- **Other:** Bootstrap, custom CSS
